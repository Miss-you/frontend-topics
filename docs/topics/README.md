## 内容等级

- **交互契约**：该组件或接入明确承诺的行为；修改时必须同步实现、测试与文档。
- **上下文建议**：在写明的条件下有帮助，可以因需求改变而调整。
- **未决问题**：当前证据不足；记录范围与关闭条件，不假装已经解决。

专题是原因和机制的长期入口。每次任务的验证时间、命令、结果与剩余事项放在复盘记录中，链接回来即可。这样既能追溯案例，也避免将过时测试数量写成永久规则。
