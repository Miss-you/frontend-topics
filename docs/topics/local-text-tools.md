# 浏览器本地文本工具

状态：消费者实践归纳。本文没有向 `daily-ui` 增加文本对比组件；示例是虚构输入，实际实现与测试由消费者维护。

## 问题与影响

文本对比器可以没有后端，仍然可能把粘贴内容交给第三方脚本、当成 HTML 执行，或在极端输入下卡住界面。因此，需求应从「不会被攻击」改写为可检验的处理边界：哪些代码能读输入，输入能流向哪里，计算何时停止。

这个场景适合放在独立工具页：左右输入、行级与行内差异、空白选项、交换、清空和显式复制。共享导航只处理菜单与外观。不要为了沿用站点布局，把评论、统计、图表脚本一并带入工具页。

## 可复现场景与证据

用两份虚构文本，从空输入、相同内容开始，再比较中文、emoji、末尾换行、CRLF，以及包含 `<img src=x onerror=alert(1)>` 的字符串。

随后输入超过约定长度或大量完全不同的行；计算中修改文本、清空或离开页面，再释放旧响应。预期是明确拒绝、允许取消或显示降级结果，旧任务不能重新填回结果。

消费者案例的证据包括纯算法测试、运行实际 UI 模块的模拟 Worker 测试、构建后策略检查及浏览器人工观察。模拟测试证明取消与响应顺序，浏览器观察补充真实渲染；两者不能相互替代。此次材料没有复制消费者测试到本仓库，也没有进行独立渗透测试。

## 解决与边界

| 处理环节   | 本次采用的办法                                          | 需要检验的失败条件                           |
| ---------- | ------------------------------------------------------- | -------------------------------------------- |
| 显示输入   | 用文本节点与 `textContent` 组成结果；高亮标签由程序创建 | 恶意标签仍作为字符显示，不能变成可执行 DOM   |
| 资源与网络 | 独立页面仅加载本地资源；收紧 CSP；不装载第三方页面脚本  | 实际构建页偷偷继承统计、评论或远程模块       |
| 持久化     | 正文只在内存处理，不放入 URL、日志或浏览器存储          | 更改主题时误把整个页面状态序列化             |
| 剪贴板     | 只响应用户明确点击复制                                  | 初始化或定时任务读取/写入剪贴板              |
| 计算       | Worker、输入上限、算法工作量预算、主线程超时与终止      | 超限、取消或 Worker 失败后控件仍锁住         |
| 旧任务     | 每次任务持有版本号；输入变更时让旧版本失效              | 迟到响应或分批 DOM 更新重新覆盖清空后的页面  |
| 大结果     | 分批渲染；预算耗尽时诚实报告粗粒度差异                  | 用「没有差异」掩盖计算未完成，或丢失原始文本 |

Worker 将计算移出界面线程，不等于计算成本有上限；超时只能终止仍在运行的任务，算法本身也需要预算。此次高亮优先用 `Intl.Segmenter` 分割字形簇，不支持时退回 `Array.from` 的代码点分割。后者可避免拆开代理对，但不保证组合字符完整；两条路径的字形语义应分别验收。

CSP 是额外约束，安全文本渲染仍需由代码保证。静态页面可以用 meta 声明部分策略，但它不支持全部 CSP 功能。参见 [MDN CSP 指南](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP)。

尤其不要把 `frame-src 'none'` 写成「禁止别人嵌入」：它控制本页加载的子框架。限制父页面的 `frame-ancestors` 不支持 meta，需要响应头；在脚本中拒绝框架内初始化只能作为有限的补充。参见 [frame-ancestors](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors)。

这些控制不保证浏览器、扩展、同源可信脚本、发布链或终端设备永远安全。若产品必须保存草稿、分享内容或接入远程服务，须重新定义这些能力的数据流，不能沿用「不保存、不上传」的描述。

## 内容等级与验收入口

| 结论                                       | 等级             | 适用范围                             |
| ------------------------------------------ | ---------------- | ------------------------------------ |
| 声明本地处理的正文不得被实现上传或自动保存 | 该工具的交互契约 | 新增同步、草稿与分享能力时须重新设计 |
| 输入必须保持数据，过期任务不得覆盖新状态   | 交互契约         | 文本工具及其他异步界面               |
| 将工具放进独立页面、使用 Worker            | 上下文建议       | 有隐私隔离或计算成本需求的页面       |
| 任何纯前端实现都绝对安全                   | 不采纳           | 缺乏可证明的边界                     |
